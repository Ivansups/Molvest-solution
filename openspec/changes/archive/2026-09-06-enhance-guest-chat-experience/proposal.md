## Why

Гостевой чат скрывал факт обработки запроса, показывал у источников только
заголовок и не позволял начать чистый диалог. Интерфейс в целом появлялся без
плавных переходов, из-за чего рабочие экраны воспринимались статично.

## What Changes

- Показать заметное состояние генерации ответа и отдельный текст для Vision-
  анализа изображения.
- Сделать источники ответа раскрываемыми: пользователь видит название документа
  и фрагмент `chunk_text`.
- Добавить гостевую CTA «Новый диалог», очищающую идентификатор и локальную
  историю перед следующим обращением.
- Добавить единую motion-систему появления интерфейсных поверхностей, сообщений,
  таблиц и модальных окон с поддержкой reduced motion.
- Разрешить loopback-хост `127.0.0.1` для ресурсов Next.js dev-сервера, чтобы
  страница гидратировалась и интерактивные элементы работали при локальном
  запуске через Docker.

## Capabilities

### New Capabilities

- `interface-motion`: Единый ненавязчивый motion-паттерн для основных UI-
  поверхностей и интерактивной CTA нового диалога.

### Modified Capabilities

- `guest-chat-ui`: Гость получает видимую обратную связь во время обработки,
  читает цитаты источников и может начать новый диалог.
- `frontend-runtime-integration`: Локальный Docker dev-стенд поддерживает
  интерактивную работу через `127.0.0.1`.

## Impact

- `frontend/src/components/pages/chat-page.tsx`, `message-bubble.tsx` и
  `use-conversation.ts`: состояние гостевого чата, источники и reset.
- `frontend/app/globals.css` и базовые UI-компоненты: motion-паттерны.
- `frontend/next.config.ts`: разрешённый локальный origin в режиме разработки.
- Backend API и форматы сообщений не меняются.
