## Why

Консоль и гостевой чат должны использовать опубликованные API этапа 6, иначе
диалоги, эскалации и метрики отображаются несогласованно с backend.

## What Changes

- Использовать единый `NEXT_PUBLIC_WORKSPACE_ID` для гостя и консоли.
- Сохранять гостевой `conversation_id` в `sessionStorage` и обновлять историю.
- Получать списки диалогов и метрики из `/api/conversations` и `/api/metrics`.
- Убрать обращения к неопубликованным API; оставить настройки явной заглушкой.

## Capabilities

### New Capabilities

_Нет._

### Modified Capabilities

- `guest-chat-ui`: гостевой диалог переживает перезагрузку вкладки.
- `frontend-runtime-integration`: подключённые API используют опубликованные
  контракты и лимиты ожидания.
- `support-console-ui`: дашборд и аналитика используют метрики этапа 6.

## Impact

- `frontend/`: сервисы, страницы чата, дашборда, аналитики и настроек.
- Backend API, Prisma-схема и OpenAPI не меняются.
