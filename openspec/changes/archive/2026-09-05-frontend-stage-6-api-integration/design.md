## Context

Backend этапа 6 создаёт и эскалирует диалог только через `POST /chat`, а
`/api/conversations` предоставляет чтение и действия оператора. Ранее часть
консоли обращалась к неопубликованным endpoint'ам.

## Goals / Non-Goals

**Goals:**
- Привязать UI к опубликованным контрактам этапа 6.
- Использовать один UUID установки во всех frontend-потоках.

**Non-Goals:**
- Добавлять `POST` или `PATCH /api/conversations`.
- Менять backend, Prisma или OpenAPI.

## Decisions

- Первый гостевой запрос без `conversation_id` создаёт диалог через `POST /chat`;
  возвращённый ID хранится в `sessionStorage`.
- Серверные дашборд и аналитика запрашивают `/api/metrics` и
  `/api/conversations` с внутренним токеном; браузер не получает токен.
- Обычные запросы ограничены 10 секундами, генерация и чат - 60 секундами.

## Risks / Trade-offs

- Дневной тренд использует доступные фильтры API по датам → это несколько
  серверных запросов, но не требует нового backend endpoint.
