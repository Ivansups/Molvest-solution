## Why

После загрузки или запуска переиндексации документ некоторое время находится в
статусе `PENDING`. Страницы базы знаний сейчас показывают это состояние только
до следующего ручного обновления, поэтому оператор не видит своевременно
результат фоновой индексации.

## What Changes

- Добавить условный React Query polling списка документов с интервалом 4 секунды,
  пока в текущей выдаче есть документ со статусом `PENDING`.
- Добавить условный polling карточки документа с тем же интервалом, пока её
  статус `PENDING`.
- Останавливать polling после получения статуса `INDEXED` или `FAILED`.
- Показывать текущий статус документа в заголовке карточки.
- Не менять backend API, формат ответов или существующие операции загрузки,
  удаления и переиндексации.

## Capabilities

### New Capabilities

- `knowledge-base-document-status-polling`: автоматическое обновление статуса
  документа в списке и карточке базы знаний.

### Modified Capabilities

Нет.

## Impact

- `frontend/src/components/pages/knowledge-base-page.tsx` — динамический
  `refetchInterval` для списка.
- `frontend/src/components/pages/knowledge-document-page.tsx` — динамический
  `refetchInterval` для карточки и отображение статуса.
- React Query и существующие типы `DocumentStatus` используются без новых
  зависимостей и изменений API.
