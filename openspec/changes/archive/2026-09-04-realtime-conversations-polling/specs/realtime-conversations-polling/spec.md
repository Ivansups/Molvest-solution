## Purpose

Автоматическое обновление списка диалогов в панели оператора через поллинг, чтобы новые эскалации и сообщения появлялись без ручного рефреша страницы.

## ADDED Requirements

### Requirement: Автоматическое обновление списка диалогов

Система SHALL автоматически обновлять список диалогов в панели оператора через периодический поллинг, чтобы новые диалоги, эскалации и сообщения появлялись без участия оператора.

#### Scenario: Оператор читает список без действий
- **WHEN** оператор открыт в панели оператора и просто читает список диалогов, ничего не отправляя
- **THEN** список автоматически обновляется с периодичностью не более 5 секунд

#### Scenario: Новая эскалация появляется без рефреша
- **WHEN** в системе создаётся новая эскалация от гостя, пока оператор читает список
- **THEN** обновлённый список содержит новую эскалацию без ручного обновления страницы

### Requirement: Чтение диалогов через бэкенд API

Панель оператора SHALL получать список диалогов и детали диалога из реальных бэкенд-эндпоинтов `GET /api/conversations` и `GET /api/conversations/{id}`, а не из заглушек.

#### Scenario: Список диалогов из API
- **WHEN** панель оператора запрашивает список диалогов
- **THEN** данные приходят из эндпоинта `GET /api/conversations`

#### Scenario: Детали диалога из API
- **WHEN** оператор открывает конкретный диалог
- **THEN** сообщения, confidence и sources загружаются из эндпоинта `GET /api/conversations/{id}`
