# knowledge-base-document-status-polling Specification

## Purpose
Автоматически показывать результат фоновой индексации документов в базе знаний
без ручного обновления страниц.
## Requirements
### Requirement: Список документов обновляется во время индексации

Страница списка документов SHALL периодически запрашивать `GET /api/documents`
через React Query, пока хотя бы один документ в текущей выдаче имеет статус
`PENDING`. Интервал SHALL быть не больше 5 секунд. Если в выдаче нет документов
со статусом `PENDING`, polling SHALL быть отключён.

#### Scenario: Новый документ появляется без F5

- **WHEN** список документов открыт и backend возвращает документ со статусом
  `PENDING`, а затем меняет его статус на `INDEXED`
- **THEN** список получает новый статус автоматически не позднее разумного
  интервала polling и не требует ручного обновления

#### Scenario: Несколько документов индексируются одновременно

- **WHEN** два или более документа в текущей выдаче имеют статус `PENDING`
- **THEN** polling продолжается, пока последний из них не перейдёт в `INDEXED`
  или `FAILED`

#### Scenario: Ошибка индексации отображается автоматически

- **WHEN** backend меняет статус документа с `PENDING` на `FAILED`
- **THEN** список показывает `FAILED`, после чего polling для выдачи отключается,
  если других `PENDING` документов нет

### Requirement: Карточка документа обновляется во время индексации

Страница карточки документа SHALL периодически запрашивать
`GET /api/documents/{id}` через React Query, пока документ имеет статус `PENDING`.
Интервал SHALL быть не больше 5 секунд. После статуса `INDEXED` или `FAILED`
polling SHALL быть отключён.

#### Scenario: Карточка показывает завершение индексации

- **WHEN** открыта карточка документа со статусом `PENDING`, а backend меняет его
  статус на `INDEXED`
- **THEN** карточка автоматически показывает `INDEXED` без F5 и прекращает
  polling

#### Scenario: Карточка показывает ошибку индексации

- **WHEN** открыта карточка документа со статусом `PENDING`, а backend меняет его
  статус на `FAILED`
- **THEN** карточка автоматически показывает `FAILED` без F5 и прекращает
  polling

### Requirement: UI показывает текущий статус карточки

Заголовок карточки SHALL отображать поле `status` из ответа документа, используя
значения `PENDING`, `INDEXED` или `FAILED`.

#### Scenario: Статус виден в карточке

- **WHEN** оператор открывает карточку документа с любым допустимым статусом
- **THEN** заголовок карточки показывает этот статус рядом с названием документа
